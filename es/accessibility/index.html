Declaración de accesibilidad

Nuestro compromiso con un sitio web accesible.

Polished Family Dental quiere que todas las personas puedan usar nuestro sitio web y recibir la atención que necesitan, incluidas las personas con discapacidad.

Nuestro estándar

Diseñamos y revisamos este sitio web para cumplir con las Pautas de Accesibilidad para el Contenido Web (WCAG) 2.1, nivel AA. Estas pautas explican cómo hacer que el contenido web sea más fácil de usar para personas ciegas o con baja visión, sordas o con dificultades auditivas, o con discapacidades motrices, del habla o cognitivas.

Lo que hacemos

  • Texto y botones con buen contraste de color, y texto que se puede agrandar sin que la página se descomponga.
  • Descripciones en las imágenes importantes para que los lectores de pantalla puedan describirlas.
  • Encabezados claros y una estructura ordenada, para que cada página sea fácil de seguir con un lector de pantalla.
  • Menús, enlaces y botones que funcionan con el teclado y muestran en qué parte de la página se encuentra.
  • Páginas que funcionan en teléfonos y tabletas, con botones grandes y fáciles de tocar.

Herramientas de otras empresas

Algunas funciones de este sitio, como las citas en línea, el chat, las reseñas, los mapas y los formularios para pacientes, son de otras empresas. Elegimos herramientas que apoyan la accesibilidad, pero no controlamos todo su contenido. Si alguna le resulta difícil de usar, llámenos y le ayudaremos directamente.

¿Necesita ayuda o encontró un problema?

Si alguna parte de este sitio web le resulta difícil de usar, o necesita la información en otro formato, comuníquese con nosotros. Díganos la página y el problema, y le ayudaremos a obtener lo que necesita y trabajaremos para corregirlo.
